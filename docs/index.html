Features

Built for real networks

Not another ping sweeper. NetScan understands quarantine periods, state transitions, and the difference between "down" and "firewalled."

🔍

Multi-Probe Engine

Auto-detects Linux capabilities for ARP and TCP SYN stealth sweeps. Falls back to unprivileged TCP Connect when needed.

🛡

Safe Availability Logic

Unresponsive hosts enter UNCERTAIN_FIREWALLED. Released only after meeting both miss threshold and quarantine duration.

📡

API-First Design

Full REST API with OpenAPI docs. Programmatic subnet management, IP provisioning, and per-IP audit history.

🔔

HMAC-SHA256 Webhooks

Signed outbound event notifications with full IP object payloads. Bounded retries with configurable backoff.

⚙

In-Process Scheduler

Background scanning with APScheduler. Zero external dependencies — no Redis, no Celery, no message queues.

🖥

HTMX Dashboard

Server-rendered CIDR matrix grid, IP inspector drawer, scan job monitor. Zero JavaScript build step.

Architecture

Clean, modular, maintainable

FastAPI + SQLModel + HTMX. No framework soup. Every module has a single responsibility.

Security

Hardened for production

Security isn't a feature. It's a requirement. Every endpoint is authenticated. Every input is validated.

🛡 CORS Enforcement

Production rejects wildcard origins. Only explicit, configured origins are allowed.

🔒 DEBUG Protection

Debug mode is blocked in production at startup. No accidental info leaks.

🌐 SSRF Blocking

DNS failure is fail-closed. Private IPs, loopback, and link-local ranges blocked. Redirect validation.

🔑 API Key Auth

X-API-Key header authentication with RBAC: admin, operator, read_only roles.

⚙ Scan Concurrency

asyncio.Semaphore limits concurrent nmap scans. Prevents resource exhaustion.

📨 Webhook Signing

HMAC-SHA256 signed outbound payloads. Verify every notification at the receiver.
